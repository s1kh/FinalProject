# Web Security Labs

**Live URL:** https://s1kh.github.io/FinalProject/

Three interactive security labs in plain HTML, CSS and JavaScript (no backend):

- IDOR (CWE-639)
- Unrestricted File Upload (CWE-434)
- Race Condition (CWE-362)

Each lab shows the vulnerable code, lets you press a payload, shows the fix, and lets you run the same payload on the fixed version.
